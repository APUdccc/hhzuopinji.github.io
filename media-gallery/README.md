# 本地媒体库

在浏览器里浏览、播放本机的视频和图片。浏览器本身不能直接读取本机路径，所以这里带了一个**零依赖的本地小服务**（`server.js`），只需要装好 [Node.js](https://nodejs.org) 18+。

## 启动

| 系统 | 方式 |
| --- | --- |
| Windows | 双击 `start.bat` |
| macOS / Linux | `./start.sh` |
| 任意 | `node server.js`，然后打开 <http://localhost:8686> |

可选环境变量：`PORT`（默认 8686）、`HOST`（默认 `127.0.0.1`，只允许本机访问）、`GALLERY_DATA`（数据目录，默认 `./data`）、`GALLERY_TOKEN`（访问口令，见下方「局域网访问」）。

> 把它部署到 GitHub Pages 是不行的：Pages 只能托管静态文件，读不到你电脑上的路径。请在本机运行。

## 使用

1. 点右上角「**后台**」→ 粘贴文件夹路径（或点「浏览…」选择）→ 添加。可添加多个路径。
2. **视频**页：进入即自动扫描，点开即可播放。
3. **图片**页：为避免一次性遍历大量文件，**必须手动点击「开始扫描」**才会扫描；结果会缓存，下次直接可用，需要时点「重新扫描」。进入某个子文件夹后还可以点「**扫描此文件夹**」，只重扫这一个目录，比整库快得多。
4. 左侧是目录树（可展开），主区是当前目录的子文件夹 + 文件；打开「包含子目录」可平铺显示下层所有内容。
5. 分类 / 筛选：
   - **名称**：搜索框（匹配文件名和所在目录），或「分类 → 名称」按首字母（A–Z、0-9、中文按拼音首字母）分组
   - **类型**：按扩展名（MP4 / MKV / JPG / PNG…）筛选或分组
   - **分辨率**：8K / 4K / 2K / 1080p / 720p / 480p / <480p / 未知（以短边判定，横竖屏一致）
   - 也可按「目录」分组；排序支持名称 / 时间 / 大小 / 分辨率 / 类型
6. **收藏夹**：缩略图右上角的 ☆ 收藏文件；文件夹旁的 ☆ 收藏文件夹（左下角「收藏的文件夹」一键直达）。收藏保存在服务端 `data/config.json`，换浏览器也在。

## 继续观看 / 字幕

- 超过 90 秒的视频会自动记住播放进度（保存在服务端，换浏览器也在），下次打开从上次位置继续；视频页的「**继续观看**」按钮只看看了一半的视频，按最近观看排序，缩略图底部有进度条。
- 视频同目录下、与视频同名的 `.srt` / `.vtt` 会自动作为字幕加载（如 `电影.srt`、`电影.zh.srt`），srt 自动转 vtt，UTF-8 / GBK 编码都能识别；在播放器右下角的字幕按钮里开关或切换。

## ffmpeg / ffprobe（可选，强烈建议安装）

| | 有 | 没有 |
| --- | --- | --- |
| 缩略图 | 服务端生成并缓存（`data/thumbs`），扫描完成后还会在后台预生成（后台 → 缩略图缓存里可改为「图片和视频」或关闭，也可清除缓存） | 图片直接用原图，视频由浏览器抽帧 |
| 视频分辨率 / 时长 | 所有格式 | MP4 / MOV / M4V / MKV / WebM 内置解析；AVI、WMV 等其它格式播放过一次后才记录 |
| 浏览器不支持的视频（HEVC、AVI、WMV…） | 播放失败时点「转码播放」实时转 H.264 | 无法播放 |

## 说明

- 只读：不会修改、移动或删除你磁盘上的任何文件；「移除媒体源」只清除索引和收藏记录。
- 支持的格式 —— 图片：jpg png gif webp bmp avif svg ico；视频：mp4 m4v mov webm mkv avi wmv flv mpg mpeg m2ts mts 3gp ogv（能否直接播放取决于浏览器）。
- 扫描会跳过以 `.` 开头的目录、`node_modules`、回收站等。
- 默认只监听 127.0.0.1，并校验 Host / Origin。

## 局域网访问（可选）

想让手机 / 平板访问：`HOST=0.0.0.0 GALLERY_TOKEN=自己设一个口令 node server.js`。第一次用 `http://电脑IP:8686/?token=口令` 打开，浏览器会记住（Cookie）。**不设口令就对外监听是不安全的**——后台能浏览本机目录，服务启动时也会给出警告。

## 开发 / 测试

`npm test`（即 `node --test test/api.test.js`）：不依赖 ffmpeg 和浏览器，运行时会生成各种格式的最小样本文件，启动真实服务并覆盖扫描、分辨率解析（PNG/JPEG/GIF/WebP/MP4/MKV）、分类筛选、目录树、只扫文件夹、收藏、继续观看、字幕、Range、路径穿越和口令校验。
